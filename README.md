# Tracking and Monitoring System — Academic Research Portal

A browser-based academic research portal for Senior High School students at AMA Santa Cruz, as described in the site's page metadata.

## Stack

HTML, CSS, and JavaScript, with externally loaded Lucide icons.

## View locally

```bash
git clone https://github.com/adyyy23/tmswebsite.git
cd tmswebsite
python -m http.server 8000
```

Open http://localhost:8000. Internet access is needed for external icon resources.

## Files

- `index.html`: portal entry page
- `chap1.html`–`chap5.html`: research chapter pages
- `script.js`: interface behavior
- `style*.css`: page styling
- `data/`, `img/`: supporting resources
- `researchfinal.pdf`: research document

This repository presents a static web interface; verify any data persistence or backend integration separately.
